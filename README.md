# Cloud-Based Secure Food Ordering System (DevSecOps)

## Project Overview
This project is a cloud-based secure Food Ordering System developed using Flask and deployed on AWS EC2 using DevSecOps practices.

The application supports:
- User Registration & Login
- Admin Dashboard
- Food Management CRUD Operations
- Image Upload
- Cart & Order System
- Payment Page
- HTTPS Secure Deployment
- Monitoring & Logging
